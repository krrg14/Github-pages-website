# Github-pages-website
## Host a Static Website with GitHub Pages

## Project Overview
Created and deployed a static website using GitHub Pages as part of the Elevate Labs DevOps Internship.

## Technologies Used
- HTML
- CSS
- JavaScript
- Git
- GitHub Pages

## Work Completed
- Created a static website using HTML.
- Customized the website using CSS.
- Added basic interactivity using JavaScript.
- Created a GitHub repository and uploaded the project files.
- Configured GitHub Pages to deploy the website from the `main` branch and root folder.
- Verified the live website in a web browser.

## Project Links
- **GitHub Repository:** `https://github.com/krrg14/Github-pages-website/`
- **Live Website:** `https://krrg14.github.io/Github-pages-website/`

## Outcome
Successfully deployed a static website using GitHub Pages and learned the basics of Git-based website hosting.
